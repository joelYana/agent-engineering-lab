# agent-engineering-lab
En 90 días voy a construir un agente diseñado para responder consultas de admisión universitaria a través de documentos oficiales de la universidad.

El stack en el que me basaré será Python, respaldado con testing con pytest, asistido por Claude Code y construido con LangGraph; se usará FastAPI para exponerlo, PostgreSQL con pgvector para la búsqueda de documentos y Langfuse para las trazas. 

El repositorio estará estructurado con una bitácora que registrará los avances por semana, un ledger con los papers explorados y un adr que guardará las decisiones técnicas documentadas.
